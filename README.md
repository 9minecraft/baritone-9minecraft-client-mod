# Baritone — Mine and Build Bases Hands-Free

Baritone 9minecraft Client Mod turns your chat box into a control center for an AI bot. It lets you type simple commands to make your character walk to exact coordinates, mine specific blocks, or construct buildings automatically. The bot calculates the fastest routes in real time while bridging gaps, digging through walls, and staying away from danger.

\t Real-Time Pathfinding: Calculates the fastest route to any spot and changes the path if terrain blocks your way.

## What this build is

An unofficial rebuild of **leijurv**'s original work, kept running on current Minecraft releases by 9Minecraft Studios. Not affiliated with the original author and not endorsed by them.

Most of the porting work sits in the mixin layer. Each Minecraft release moves or renames the methods this mod hooks into, so the hooks are re-pointed and re-tested against that version rather than rewritten. The behaviour underneath is upstream's and is deliberately left alone — that is the part that makes the mod feel right, and it is not ours to redesign.
